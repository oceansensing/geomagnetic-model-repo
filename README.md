# geomagnetic-model-repo

The Earth's main magnetic field from the World Magnetic Models, as gridded data
for the oceansensing.org ocean map: declination, inclination and the total,
horizontal, vertical, north and east intensities on a 0.25° world, each one's
yearly change, and the compass's blackout and caution zones at 0.5° — where the
horizontal field is under 2,000 nT (2) or 6,000 nT (1), as NOAA defines them.
Each grid is the field at the first instant of its month.

Updated daily; the values change when the month turns.
